The Medallion contract

All three layers fall out of one Spark application, storage_writer.py, writing Parquet under storage/data/ partitioned by symbol. Nothing re-reads a layer's files yet — each is a branch of the same Kafka read, which is what makes the split cheap to run on a laptop.
